Campus background photos
========================

Every .jpg / .jpeg / .png / .webp / .avif file in this folder becomes a slide
in the moving background behind the whole site (App.razor + js/live-bg.js).

- Order: by file name, so name them 01-gate.jpg, 02-library.jpg, ...
- Size: landscape, about 1920 px wide, under ~500 KB each (they load on every page).
- After adding or removing photos just reload the page (no restart needed).
- No photos here = the animated contour-line background is used instead.
